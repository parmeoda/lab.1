# Lab: Grade Reader

## Project Description
This program reads student names and their grades from a text file called grades.txt and then shows them on the screen. It uses a Scanner to read the file line by line and a try-catch block to handle errors if the file cannot be found.

## How to Run
1. Open the Java project in IntelliJ.
2. Make sure the grades.txt file is in the project folder.
3. Run Main.java.
4. The program will display the student names and their grades on the screen.

## Example Output
```
Student Grades:
John: 85
Sara: 92
Mark: 78
```

If the file cannot be found, the program will display:
```
File not found!
```
